# healthBridge-web

Health bridge web repo — Next.js (App Router) frontend for OHealth.

## Getting started

Install dependencies, then run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

You can edit the home page in `src/app/page.js`; changes hot-reload while the dev server is running.

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — production build
- `npm run start` — run the production server
- `npm run lint` — ESLint
